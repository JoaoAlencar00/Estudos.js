# Fundamentos de JavaScript

Repositório de estudos com exemplos e exercícios sobre tipos de dados, variáveis, operadores e funções em JavaScript.

## Conteúdo

Os exemplos estão na pasta `Cursojs/`, organizados por tema:

- Tipos primitivos: strings, números, booleanos, `null` e `undefined`.
- Declaração de variáveis e escopo.
- Operadores aritméticos, de comparação e lógicos.
- Funções com parâmetros e retorno.
- Expressões de função e arrow functions.
- Exercícios e observações sobre erros.

## Como executar

Instale o Node.js e execute um arquivo por vez a partir da raiz:

```bash
git clone https://github.com/JoaoAlencar00/Estudos.js.git
cd Estudos.js
node Cursojs/funcoes.js
```

O exemplo imprime informações de estudantes no terminal. Para consultar outro tema, substitua o caminho pelo arquivo correspondente.

Não há dependências externas. Parte das resoluções em `atividades.js` está comentada e serve como material de consulta.

## Objetivo

Consolidar a base da linguagem por meio de exemplos pequenos e independentes, registrando os conceitos praticados ao longo dos estudos.
